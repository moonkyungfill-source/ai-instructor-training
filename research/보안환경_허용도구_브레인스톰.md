# 보안 환경에서 쓸 수 있는 AI 자동화 도구 브레인스톰

## 보안 등급별 분류

---

### TIER 1: 회사에 이미 있는 도구 (보안 승인 불필요)

> 대부분의 기업에서 이미 라이선스를 보유하고 있어 별도 승인 없이 사용 가능

| 도구 | 뭘 할 수 있나 | 강의 콘텐츠 예시 |
|------|--------------|-----------------|
| **Excel VBA** | 매크로, 다중 파일 처리, 보고서 자동 생성 | 자금일보, 생산일보, 채권연령표 자동화 |
| **Excel Power Query** | 데이터 수집·변환·병합 (코딩 불필요!) | 여러 부서 엑셀 → 월간 종합 리포트 자동 생성 |
| **Google Sheets + Apps Script** | 스프레드시트 자동화, 이메일 발송, 트리거 | 주간 매출 보고서 자동 집계+발송 |
| **Google Drive** | 파일 관리, 공유, 자동 백업 | PC 연동, 폴더 자동 정리 |
| **OneDrive** | 파일 관리, SharePoint 연동 | Windows 탐색기 마운트, 자동 동기화 |
| **Outlook 규칙/VBA** | 이메일 자동 분류, 자동 회신, 알림 | 결재 요청 자동 알림, 첨부파일 자동 저장 |
| **Word 메일 머지** | 대량 문서 자동 생성 | 계약서, 증명서, 발송장 일괄 생성 |
| **Windows 작업 스케줄러** | 스크립트 예약 실행 | 매일 아침 자동 보고서 생성 |
| **PowerShell** | Windows 시스템 자동화 | 파일 정리, 백업, 데이터 변환 스크립트 |

---

### TIER 2: M365/Google 라이선스에 포함된 AI 도구 (기업용 라이선스 범위)

> 기업이 M365나 Google Workspace를 쓰고 있다면 추가 승인 없이 사용 가능할 가능성 높음

| 도구 | 뭘 할 수 있나 | 강의 콘텐츠 예시 |
|------|--------------|-----------------|
| **Microsoft 365 Copilot** | Excel 수식 생성, PPT 자동 생성, 이메일 요약 | "이 데이터로 피벗 테이블 만들어줘" |
| **Power Automate** | 워크플로우 자동화 (RPA) — 코딩 불필요! | 이메일 첨부파일 → OneDrive 저장 → Teams 알림 |
| **Power Apps** | 로우코드 업무 앱 제작 | 재고 관리 앱, 출장 신청 앱 |
| **Power BI** | 데이터 시각화 대시보드 | 매출/생산/재무 실시간 대시보드 |
| **Google Gemini for Workspace** | Sheets/Docs/Gmail AI 보조 | "이 시트 데이터를 분석해줘" |
| **Google AppSheet** | 노코드 앱 제작 (Sheets 데이터 기반) | 현장 점검 앱, 재고 조사 앱 |
| **Google Looker Studio** | 데이터 시각화 (무료!) | 마케팅/영업 성과 대시보드 |
| **Microsoft Forms → Excel** | 설문/입력 → 자동 집계 | 일일 보고 입력 → 자동 종합 |

### TIER 3: 별도 승인 필요하지만 기업용 보안 인증 있는 도구

> SOC2, ISO27001 등 보안 인증을 갖추고 있어 기업 승인을 받기 수월

| 도구 | 뭘 할 수 있나 | 강의 콘텐츠 예시 |
|------|--------------|-----------------|
| **GitHub Copilot (Business/Enterprise)** | AI 코드 생성, CLI로 자연어 → 스크립트 | "채권연령표 만드는 VBA 코드 짜줘" |
| **Google AI Studio** | 바이브코딩, 웹앱 생성 | 업무용 미니 도구를 대화로 제작 |
| **Claude (Enterprise)** | 문서 분석, 코드 생성, 데이터 처리 | 계약서 검토, 보고서 초안 |
| **n8n (Self-hosted)** | 워크플로우 자동화 (오픈소스, 자체 서버) | 사내 서버에 설치 → 외부 유출 제로 |
| **Zapier (Enterprise)** | 앱 간 자동화 연결 | Slack → Sheets → Email 파이프라인 |

### TIER 4: 데이터가 절대 밖으로 안 나가는 로컬 AI

> 인터넷 연결 불필요, 회사 PC에서만 동작 — 가장 강력한 보안

| 도구 | 뭘 할 수 있나 | 강의 콘텐츠 예시 |
|------|--------------|-----------------|
| **Ollama** | 로컬 LLM 실행 (Llama, Gemma, Mistral 등) | 사내 PC에서 AI 문서 요약/분석 |
| **LM Studio** | 로컬 LLM + GUI (비개발자 친화) | 클릭만으로 AI 챗봇 실행 |
| **Windows Copilot** | Windows 11 내장 AI | 파일 검색, 설정 변경, 텍스트 작업 |
| **Python + pandas/openpyxl** | 로컬 데이터 처리 | 엑셀 파일 일괄 처리 (오프라인) |

## 강의 콘텐츠 아이디어 맵

### A. "코딩 제로" 자동화 (비개발자 최우선)

```
Excel Power Query   → 데이터 수집·변환 (드래그앤드롭)
Power Automate      → 업무 흐름 자동화 (블록 조립)
Power Apps          → 나만의 업무 앱 (로우코드)
Google AppSheet     → 시트 기반 모바일 앱
Microsoft Forms     → 데이터 수집 자동화
Looker Studio       → 대시보드 시각화
```

### B. "AI에게 코드 짜달라고 하기" 자동화

```
GitHub Copilot CLI  → "자금일보 만드는 VBA 코드 짜줘"
Google AI Studio    → "재고 대시보드 웹앱 만들어줘" (바이브코딩)
M365 Copilot        → "이 데이터로 피벗 만들어줘"
Gemini for Sheets   → "이 열을 기준으로 분류해줘"
```

### C. "매일 알아서 돌아가는" 자동화

```
Apps Script 트리거  → 매일 오전 9시 보고서 자동 생성+발송
Power Automate      → 이메일 첨부 → OneDrive → Teams 알림
Windows 작업 스케줄러 → 매일 새벽 데이터 백업
VBA + 작업 스케줄러  → 매일 자금일보 자동 생성
```

### D. "내 PC에서만 도는 AI" (최고 보안)

```
Ollama/LM Studio    → 문서 요약, 번역, 분류 (오프라인)
Python + AI 라이브러리 → 로컬 데이터 분석
PowerShell          → 파일 자동 정리, 시스템 관리
```
