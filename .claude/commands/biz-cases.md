# 부서별 비즈니스 활용 케이스 개발

## 목적

각 부서(재무, 생산, 회계, 영업, 총무, 인사 등)에서 바로 쓸 수 있는 AI 자동화 활용 케이스 개발

## 케이스 설계 원칙

1. **"월요일에 바로 쓸 수 있는가?"** 테스트 통과 필수
2. 비개발자가 AI에게 시켜서 30분 안에 만들 수 있는 수준
3. 로컬 네트워크 공유로 팀원이 바로 사용 가능
4. 보안 조건 명시 (어떤 데이터 등급까지 가능한지)
