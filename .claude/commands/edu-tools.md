# 에듀테크 도구 활용 + QR 배포 + 실시간 Q&A

## 목적

교육 자료를 QR 코드로 즉시 배포하고, 에듀테크 도구로 실시간 Q&A/투표/퀴즈를 진행하여
수강생 참여도를 극대화한다.

## QR 코드 배포 시스템

### QR 코드 생성 대상
```
[ ] 수업 자료 다운로드 링크 (더미 데이터, 80% 템플릿)
[ ] AI 서비스 접속 URL (Gemini, Copilot, Claude 등)
[ ] 설치 가이드 영상 링크
[ ] 실시간 Q&A 접속 링크
[ ] 만족도 설문 링크
[ ] 용어집 PDF 다운로드 링크
```

### QR 코드 배포 방법
1. **교육장 인쇄물**: A4에 QR 6~8개 인쇄 → 각 책상에 비치
2. **첫 슬라이드**: 강사 PPT 첫 화면에 "자료 다운로드" QR
3. **회차별 슬라이드**: 각 회차 시작 시 해당 회차 실습 자료 QR
4. **이메일 사전 발송**: 교육 전날 QR + 직접 링크 이메일

### QR 코드 생성 도구
- **무료**: qr-code-generator.com, goqr.me
- **단축 URL**: bit.ly (클릭 통계 확인 가능)
- **동적 QR**: 교육 후 링크 변경/비활성화 가능 (유료)

### QR 접속 테스트 체크리스트
```
[ ] 수강생 스마트폰 카메라로 QR 스캔 → 접속 확인
[ ] 사내 와이파이에서 QR 링크 접속 가능 여부
[ ] PC 카메라로 QR 스캔 (Windows 카메라 앱)
[ ] 링크가 로그인 필요 시 → 사전 계정 준비 안내
```

## 에듀테크 도구 활용

### 실시간 Q&A 도구 (택 1)

| 도구 | 특징 | 비용 | 추천 상황 |
|------|------|------|----------|
| **Slido** | 실시간 질문 + 투표 + 퀴즈 | 무료(기본) | 기업 교육 표준 |
| **Mentimeter** | 워드클라우드 + 투표 + 퀴즈 | 무료(2개 슬라이드) | 시각적 인터랙션 |
| **Padlet** | 포스트잇 보드 + 파일 공유 | 무료(3개 보드) | 아이디어 수집 |
| **Google Forms** | 설문 + Q&A | 무료 | 가장 범용적 |
| **MS Forms** | 설문 + 퀴즈 | M365 포함 | MS 환경 기업 |

### 회차별 에듀테크 활용 계획

| 회차 | 시점 | 도구 | 활용 |
|------|------|------|------|
| **1회차** | 블록1 시작 | Mentimeter 워드클라우드 | "AI하면 떠오르는 단어?" → 분위기 형성 |
| **1회차** | 블록4 끝 | Slido Q&A | 자동화 대상 업무 공유 + 동료 투표 |
| **2회차** | 블록1 시작 | Slido 퀴즈 | "지난 시간 복습 퀴즈 3문제" (1분) |
| **2회차** | 블록5 끝 | Padlet | 자금일보 자동화 결과 캡처 → 공유 보드 |
| **3회차** | 블록4 끝 | Slido 투표 | "우리 부서에 Agent 쓸 수 있는 업무?" 투표 |
| **4회차** | 블록3~4 | QR 코드 | 만든 대시보드 QR → 팀원 접속 |
| **5회차** | 블록2 | Slido 퀴즈 | "Solar vs Gemma, 어떤 게 더 잘했나?" 투표 |
| **6회차** | 블록5 | Mentimeter 투표 | "가장 유용했던 회차?" + 만족도 설문 |

### 에듀테크 QR 코드 통합 흐름

```
[교육 전날]
  이메일로 QR 코드 모음 발송 (자료 다운로드, Q&A 접속, 설문)

[매 회차 시작]
  슬라이드에 QR 표시 → "스마트폰으로 스캔하세요"
  → Slido/Mentimeter 접속 → 워밍업 질문/퀴즈

[실습 중]
  "질문 있으면 Slido에 올려주세요" → 강사가 실시간 확인
  → 중요 질문은 전체 답변, 개인 질문은 1:1 지원

[실습 결과 공유]
  Padlet에 결과 캡처 올리기 → 동료 결과 구경 + 좋아요
  4회차 대시보드 → QR로 상호 접속

[회차 마무리]
  "오늘 수업 한 줄 소감" → Mentimeter 워드클라우드
  → 월요일 액션 플랜 Slido에 공유

[6회차 수료]
  만족도 설문 QR → 즉시 수거
  교육 효과 퀴즈 (사전/사후 비교)
```

## 사전 준비 체크리스트

```
[ ] 에듀테크 도구 선택 (Slido/Mentimeter/Padlet)
[ ] 교육용 방(Room) 사전 생성 + 접속 코드 확보
[ ] 접속 코드 QR 코드로 변환
[ ] 수강생 PC/스마트폰에서 접속 테스트
[ ] 사내 와이파이에서 해당 도구 접속 가능 여부 확인
[ ] 회차별 퀴즈/투표/워드클라우드 사전 제작
[ ] QR 코드 인쇄물 준비 (교육장 비치용)
[ ] 강사 PPT에 QR 코드 삽입
```

## $ARGUMENTS

- 없으면: 범용 에듀테크 계획 생성
- 트랙명(google/ms/claude): 해당 트랙에 맞춘 에듀테크 계획
- 기업명: 해당 기업 IT 환경에 맞춘 도구 추천
