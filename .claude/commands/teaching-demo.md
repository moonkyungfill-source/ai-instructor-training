# 강의 시연 준비 가이드

## 목적

5~10분 강의 시연 영상 준비를 위한 대본 및 슬라이드 구성 지원

## 요구사항 (채용 공고 기준)

- 실제 강의 스타일과 전달력 확인용
- 5~10분 내외 녹화 영상
- 기존 강의 녹화본 또는 자유 주제 시연 모두 가능

## 작업 흐름

### 1단계: 주제 선정

$ARGUMENTS 에 주제가 있으면 해당 주제, 없으면 다음 중 추천:
- AI Agent 개발 입문 (MCP + Tool Use)
- RAG 파이프라인 구축 실습
- LLM API 활용 첫 번째 애플리케이션
- Prompt Engineering 핵심 기법
- Document AI로 문서 자동화하기

**선정 기준**: 업스테이지 기술과 연관, 실습 시연 가능, 10분 내 전달 가능

### 2단계: 시연 구조 설계

**10분 기준 시간 배분:**
| 구간 | 시간 | 내용 |
|------|------|------|
| 도입 | 1분 | 주제 소개, 학습 목표, 동기 부여 |
| 개념 설명 | 2분 | 핵심 개념을 시각적으로 설명 |
| 라이브 코딩/실습 | 5분 | 실제 코드 작성 및 실행 시연 |
| 정리 | 1분 | 핵심 요약, 다음 단계 안내 |
| 버퍼 | 1분 | Q&A 또는 추가 설명 |

### 3단계: 대본 작성

- 슬라이드별 발화 내용 (키워드 + 자연스러운 멘트)
- 실습 코드 준비 (동작 확인 완료된 코드)
- 전환 멘트 (자연스러운 흐름)
- 학습자 참여 유도 질문

### 4단계: 슬라이드 구성

- 슬라이드 개수: 5~8장
- 텍스트 최소화, 시각 자료 활용
- 코드 하이라이트 포함
- 업스테이지 관련 기술 자연스럽게 노출

## 출력 형식

1. **주제 및 학습 목표**
2. **시간 배분표**
3. **슬라이드별 구성안** (제목, 내용, 발화 포인트)
4. **실습 코드** (복사 가능한 형태)
5. **녹화 팁** (조명, 마이크, 화면 구성 등)

## 평가 포인트 (예상)

- 전달력: 명확하고 자신감 있는 설명
- 구조화: 논리적 흐름, 시간 관리
- 실무성: 실제 동작하는 코드, 실무 적용 사례
- 상호작용: 질문 유도, 학습자 참여
- 기술력: 최신 AI 기술에 대한 깊은 이해
