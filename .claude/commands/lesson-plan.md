# 트랙별 수업계획서 작성/수정

## 목적

Google / Microsoft / Claude 트랙별 상세 수업계획서 작성 및 수정

## 수업 설계 원칙 (필수 준수)

### 비개발자 따라하기 원칙
1. **30분 성공 경험**: 매 회차 시작 30분 안에 수강생 화면에 결과물
2. **회차당 핵심 도구 1~2개**: 5개 도구 ❌ → 1개 깊이 ✅
3. **체험 먼저, 이름은 나중에**: 실습 → 개념 이름 붙이기
4. **웹 브라우저 우선**: 설치형 도구에 반드시 웹 대안(플랜B)
5. **80% 완성 템플릿 제공**: 빈 칸 시작 ❌

### 4시간 시간 블록 템플릿
```
[블록1] 0:00~0:50  도입 + 30분 성공 경험 (강의 15분 + 미니실습 35분)
[블록2] 0:50~1:40  메인 실습 (시연 10분 + 따라하기 40분)
        1:40~2:00  휴식
[블록3] 2:00~2:50  심화 실습 (시연 10분 + 따라하기 40분)
[블록4] 2:50~3:40  응용/자유 실습 (50분)
[블록5] 3:40~4:00  정리 + 월요일 액션 플랜 (20분)
```

### 인지 부하 체크
- 새 도구: 회차당 최대 2개
- 새 개념: 회차당 최대 2개
- 새 용어: "쉬운 말" 병기 필수 (예: Agent → "스스로 판단하는 AI 도우미")

### 보안 원칙
- 도구별 보안 조건을 **정확히** 명시 ("최강 보안" 같은 과장 금지)
- AI 코드 검증 4단계: 말하기 → 받기 → 검증하기 → 실행하기
- 데이터 4등급 분류 적용

### 🔴 라이센스/학습정책 경고 (필수)
- **모든 도구에 🔴/🟡/🟢 학습정책 태그** 표시
- 🔴 무료 = 학습 사용 → 더미 데이터 필수, 실제 업무 데이터 금지
- 🟡 조건부 = 유료 플랜에서만 안전 → 플랜 확인 안내
- 🟢 안전 = 데이터 미학습 / 로컬 실행
- **강사 경고 문구**: 각 실습 시작 전 수강생에게 말할 한 줄 필수

### 📋 ISMS-P 관련 조항 표시 (필수)
- 각 실습이 관련되는 **ISMS-P 기준 번호** 표시
- 2.2.4 교육훈련 / 2.1.3 정보자산 / 2.3.1 외부서비스 / 2.6 접근통제 등

### ⚠️ 개인정보 주의 (필수)
- 실습 데이터에 개인정보 포함 여부 체크
- 더미 데이터 사용 안내
- 교육 후 데이터 정리 가이드

### 기업 환경 대응
- 모든 설치형 도구에 웹 기반 플랜B 준비
- 관리자 권한 없는 PC 전제
- 사전 IT 협조 체크리스트 포함
- **교육 전 기업의 AI 플랜(무료/유료) 반드시 확인**

### 🔒 문서보안 DRM 대응 (필수 체크)
- 기업에 DRM(Fasoo/SoftCamp/MarkAny 등)이 있는지 사전 확인
- DRM 환경에서는 **"Excel 앱 내부에서 동작하는 방식"** 우선:
  - ✅ VBA, Claude in Excel, xlwings, Power Query → DRM 통과
  - ❌ openpyxl, pandas, Document AI → DRM 차단
- Python 코드가 엑셀을 읽어야 하면 **xlwings 사용** (Excel 앱 제어 방식)
- DRM 없는 더미 데이터 사전 준비 필수

## 작업 흐름

$ARGUMENTS에 트랙명이 지정되면 해당 트랙만, 없으면 3트랙 모두 작성.

1. 현재 수업계획서 읽기
2. 위 원칙에 따라 검증/수정
3. Word 파일로 출력
