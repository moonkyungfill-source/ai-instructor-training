# 수업계획서 HTML 1페이지 요약본 생성

## 목적

3트랙 수업계획서를 **시각적으로 한눈에 보이는 HTML 1페이지 요약본**으로 생성.
기업 담당자/수강생에게 수업 구성을 빠르게 전달하는 용도.

## 반드시 포함할 내용

### 상단 헤더
- 과정명: "AI로 쉬워지는 직장인 업무 자동화"
- 트랙명 + 핵심 도구 아이콘
- 총 시간: 24시간 (6회 × 4시간)

### 6회차 타임라인 (시각적)
- 각 회차를 카드 또는 타임라인으로 표시
- 회차별: 제목, 30분 성공 경험, 핵심 도구, 가져가는 것
- 색상으로 구분 (Google=녹색, MS=파랑, Claude=주황)

### 보안 등급 표시
- 각 회차의 🔴/🟡/🟢 보안 태그
- "더미 데이터 사용" 안내

### 비즈니스 활용 케이스 (하단)
- 부서별 효과 테이블 (재무/생산/회계/영업)

### 하단 푸터
- 강사 정보
- ISMS-P 준수 안내
- "수업 전 IT 부서 협조 필요" 안내

## 디자인 원칙

- **1페이지에 모든 정보** (스크롤 최소화)
- **인쇄 가능** (A4 가로)
- 모바일 반응형
- 깔끔하고 전문적인 디자인 (기업 담당자가 경영진에게 보고할 수 있는 수준)
- Tailwind CSS CDN 또는 인라인 스타일 사용
- 한국어

## 생성 방법

$ARGUMENTS에 트랙명이 있으면 해당 트랙, 없으면 3트랙 전부 생성.

각 트랙별 HTML 파일 생성:
- `summary_Google_트랙.html`
- `summary_Microsoft_트랙.html`
- `summary_Claude_트랙.html`
