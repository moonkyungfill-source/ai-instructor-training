# 비개발자 따라하기 자동 체크 (수업계획서 품질 게이트)

## 목적

수업계획서가 **비개발자(코딩 경험 없는 40대 사무직)**도 따라할 수 있는지
자동 체크리스트로 검증하는 품질 게이트. 수업계획서 작성/수정 후 반드시 실행.

## 사용 시점

- `/lesson-plan` 으로 수업계획서를 작성/수정한 **직후**
- 검토 에이전트를 돌리기 **전** 셀프 체크
- Word 파일 최종 생성 **전**

## 자동 체크리스트 (18개 항목)

각 항목을 수업계획서에서 확인하고 PASS/FAIL 판정.

### A. 30분 성공 경험 (3개)

```
[ ] A-1. 모든 6회차의 블록1(0:00~0:50)에 "30분 성공 경험"이 명시되어 있는가?
[ ] A-2. 30분 성공 경험이 "수강생 화면에 결과물이 나오는 것"인가? (강의만 듣는 것 ❌)
[ ] A-3. 1회차 30분 성공이 "웹 브라우저만으로" 달성 가능한가? (설치 필요 ❌)
```

### B. 인지 부하 (3개)

```
[ ] B-1. 모든 회차에서 새 도구 수 ≤ 2개인가?
[ ] B-2. 모든 회차에서 새 개념 수 ≤ 2개인가?
[ ] B-3. 1회차에 CLI/터미널/코드 편집기가 등장하지 않는가?
```

### C. 용어 (3개)

```
[ ] C-1. 전문 용어(Agent, MCP, Agentic, CLI 등)에 "쉬운 말" 병기가 있는가?
[ ] C-2. "체험 먼저, 이름은 나중에" 원칙이 지켜지는가? (용어 설명 → 실습 ❌, 실습 → 용어 설명 ✅)
[ ] C-3. 수강생 용어집(A4 1장)이 부록에 포함되어 있는가?
```

### D. 실습 현실성 (3개)

```
[ ] D-1. 모든 실습에 "80% 완성 템플릿"이 제공되는가? (빈 칸 시작 ❌)
[ ] D-2. 에러 대응법("에러를 AI에게 보여주세요")이 교육되는가?
[ ] D-3. 모든 설치형 도구에 웹 기반 플랜B가 명시되어 있는가?
```

### E. 보안 이해 가능성 (3개)

```
[ ] E-1. 데이터 4등급 분류가 "우리 회사 데이터로" 실습되는가? (이론만 ❌)
[ ] E-2. AI 코드 검증 4단계가 실습으로 체험되는가? (설명만 ❌)
[ ] E-3. 🔴 도구 실습마다 "더미 데이터만 사용" 경고가 있는가?
```

### F. 수업 후 지속 가능성 (3개)

```
[ ] F-1. 매 회차 "월요일 액션 플랜"(다음 주 적용할 것 1개)이 있는가?
[ ] F-2. 6회차에 "교육 후 데이터 정리 가이드"가 포함되어 있는가?
[ ] F-3. 결과물을 USB/메일로 가져갈 수 있도록 안내되어 있는가?
```

## 판정 기준

| PASS | 18개 중 16개 이상 PASS |
| WARNING | 14~15개 PASS |
| FAIL | 13개 이하 — 수정 후 재검증 필요 |

## 실행 방법

수업계획서 파일(Word 또는 Python 스크립트)을 읽고, 18개 항목을 하나씩 체크.
$ARGUMENTS에 트랙명이 있으면 해당 트랙만, 없으면 3트랙 전부.

## 출력 형식

```
## 비개발자 체크 결과 — [트랙명]

A. 30분 성공: [PASS] A-1 ✅ A-2 ✅ A-3 ✅
B. 인지 부하: [PASS] B-1 ✅ B-2 ✅ B-3 ✅
C. 용어:      [WARN] C-1 ✅ C-2 ✅ C-3 ❌ (용어집 미포함)
...
종합: 17/18 [PASS]
```
