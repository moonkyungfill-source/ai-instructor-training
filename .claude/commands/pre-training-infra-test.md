# 수업 전 IT 인프라 환경 테스트

## 목적

교육 **1주 전**에 실제 수강생 PC/네트워크에서 모든 도구가 동작하는지 **실측 테스트**.
"교육 당일에 안 돼요"를 원천 차단.

## 사용 시점

- `/pre-training-checklist` 의 Phase 3 (3일 전)과 연동
- IT 담당자와 함께 수강생 PC 1대에서 실측
- 결과를 마크다운/Word로 기록하여 교육 당일 참조

## 테스트 항목 (5개 카테고리, 25개 항목)

---

### 1. 네트워크/와이파이 환경 (6개)

```
[ ] 1-1. 교육장 와이파이 SSID 확인 + 비밀번호 수강생 배포 준비
[ ] 1-2. 동시 접속 테스트: 수강생 수(20명) × 동시 접속 시 속도 측정
        - speedtest.net 결과: 다운 ___Mbps / 업 ___Mbps
        - 20명 × AI 서비스 동시 사용 시 최소 100Mbps 다운 권장
[ ] 1-3. 와이파이 대역 확인: 5GHz 사용 가능? (2.4GHz는 동시 접속 시 느림)
[ ] 1-4. 유선 랜 사용 가능 여부 (와이파이 불안정 시 강사용 유선 확보)
[ ] 1-5. 게스트 와이파이 vs 사내 와이파이: 외부 서비스 접속 제한 차이
[ ] 1-6. VPN 필요 여부: 사외에서 접속 시 VPN 필요한 서비스 있는지
```

### 2. AI 서비스 접속 테스트 (8개)

```
수강생 PC에서 실제로 접속하여 확인 (프록시/방화벽 실측)

[Google 트랙]
[ ] 2-1. gemini.google.com 접속 + 질문 전송 → 응답 확인
[ ] 2-2. aistudio.google.com 접속 + API 호출 테스트
[ ] 2-3. labs.google.com (Opal) 접속 → 앱 생성 가능 여부
[ ] 2-4. script.google.com (Apps Script) → 편집기 열기 + 코드 실행

[Microsoft 트랙]
[ ] 2-5. github.com/copilot 접속 + 대화 테스트
[ ] 2-6. OneDrive 접속 + 파일 업로드 + 공유 링크 생성

[Claude 트랙]
[ ] 2-7. claude.ai 접속 + 대화 + 파일 업로드 테스트

[공통]
[ ] 2-8. api.upstage.ai (Document AI) → API 호출 테스트
```

### 3. 소프트웨어 설치/실행 테스트 (5개)

```
[ ] 3-1. VBA 매크로 실행 가능 여부:
        - Excel 열기 → 개발 도구 탭 존재? (없으면 활성화 필요)
        - Alt+F11 → VBA 편집기 열림?
        - 샘플 매크로 실행 → 보안 경고 해제 가능?
        - DRM 파일에서 VBA 실행 → 동작?

[ ] 3-2. PowerShell 실행 정책 확인:
        - PowerShell 열기 → `Get-ExecutionPolicy` 실행
        - 결과: _____ (Restricted이면 스크립트 실행 불가)
        - `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` 가능?

[ ] 3-3. Chrome 확장 설치 가능 여부:
        - Chrome 웹스토어 접속 가능?
        - 확장 프로그램 설치 버튼 활성화?
        - 그룹 정책으로 차단되어 있는지?

[ ] 3-4. 5회차 로컬 AI (교육 전 설치 필요):
        - LM Studio 설치 가능? (.exe 실행 권한)
        - Ollama 설치 가능? (관리자 권한 필요)
        - 모델 다운로드: huggingface.co 접속 가능?
        - USB에서 모델 파일 복사 가능? (USB 차단 여부)
        - GPU 유무 확인: 없으면 CPU 모드 (느리지만 동작)

[ ] 3-5. Claude Desktop / gh CLI (해당 트랙만):
        - Claude Desktop .exe 설치 가능?
        - Node.js 설치 가능? (MCP 의존)
        - gh CLI 설치 가능? (git 의존)
```

### 4. CLI 사전 설치 가이드라인 (3개)

```
[ ] 4-1. CLI 사전 설치 가이드 문서 제작:
        - 스크린샷 포함 단계별 설치 가이드 (A4 2~3장)
        - Windows 기준: 다운로드 URL → 설치 → 첫 실행 확인
        - 대상: Ollama, LM Studio, gh CLI (해당 트랙만)

[ ] 4-2. CLI 사전 설치 영상 제작:
        - 3~5분 짧은 영상 (화면 녹화 + 음성 안내)
        - "이 영상을 보고 교육 전에 설치해주세요"
        - YouTube 비공개 또는 Google Drive/OneDrive 링크로 배포

[ ] 4-3. 설치 완료 확인 설문:
        - Google Forms / MS Forms로 "설치 완료했나요?" 설문
        - 미완료자 파악 → 교육 당일 조기 도착하여 지원
```

### 5. 교육 자료 배포 환경 테스트 (3개)

```
[ ] 5-1. QR 코드 접속 테스트:
        - 교육 자료 링크를 QR 코드로 변환
        - 수강생 스마트폰에서 QR 스캔 → 접속 확인
        - PC 카메라로 QR 스캔 가능 여부 (Windows 카메라 앱)
        - QR 코드 인쇄물 준비 (교육장 벽면/책상 비치)

[ ] 5-2. 파일 배포 경로 테스트:
        - OneDrive/Google Drive 공유 링크 → 수강생 접속 가능?
        - 이메일 첨부 → 수신 가능? (첨부 크기 제한?)
        - USB → 차단 여부?
        - 사내 파일 서버 → 접근 가능?

[ ] 5-3. 빔프로젝터/모니터 테스트:
        - HDMI/USB-C 연결 → 화면 출력 확인
        - 해상도: 강사 화면이 뒤에서도 보이는 크기
        - 듀얼 모니터: 강사 화면 + 발표 화면 분리 가능?
```

## 출력

테스트 결과를 마크다운 또는 Word로 저장:
- `infra_test/인프라테스트_[기업명]_YYYYMMDD.md`
- 각 항목: PASS/FAIL + 메모
- FAIL 항목에 대한 플랜B 결정 기록
