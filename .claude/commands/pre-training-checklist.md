# 수업 전 기업 교육담당자 조율 체크리스트

## 목적

교육 **2~4주 전**에 기업 교육담당자/IT팀과 조율해야 할 사항을 체크리스트로 관리.
이 리스트를 빠짐없이 확인해야 교육 당일 "안 돼요" 사태를 예방할 수 있다.

## 사용 시점

- 교육 확정 직후 → 기업 담당자에게 체크리스트 전달
- 교육 2주 전 → 미완료 항목 재확인
- 교육 3일 전 → 최종 확인 + 플랜B 결정

## 체크리스트 (35개 항목)

---

### Phase 1: 교육 확정 직후 (4주 전)

#### 1. 트랙 결정 🎯

```
[ ] 1-1. 기업의 주력 AI 생태계 확인 (Google Workspace / Microsoft 365 / Claude)
[ ] 1-2. 트랙 결정: Google / Microsoft / Claude
[ ] 1-3. 수강생 인원 확인 (20명 이하 권장, 20명 초과 시 조교 필요)
[ ] 1-4. 수강생 직무/부서 확인 (재무? 생산? 회계? → 실습 시나리오 맞춤)
[ ] 1-5. 교육 일정 확정 (6회 × 4시간, 주 1회? 집중 3일?)
```

#### 2. 보안/라이센스 확인 🔒

```
[ ] 2-1. 기업의 AI 사용 정책 확인 (어떤 AI가 승인되어 있는가?)
[ ] 2-2. AI 도구 플랜 확인 (무료 vs 유료):
        - Google: Workspace 유료 + Gemini add-on?
        - MS: Copilot Business/Enterprise?
        - Claude: Teams/Enterprise?
[ ] 2-3. 무료 플랜만 있는 경우 → "더미 데이터만 사용" 원칙 합의
[ ] 2-4. ISMS-P 인증 기업인지 확인 → 교육 증빙 양식 준비
[ ] 2-5. 문서보안 DRM 솔루션 확인 (Fasoo? SoftCamp? MarkAny?)
[ ] 2-6. DRM 환경에서 VBA 매크로 실행 가능 여부 테스트 요청
```

#### 3. IT 환경 확인 💻

```
[ ] 3-1. 수강생 PC 사양: OS, RAM, GPU 유무
[ ] 3-2. 관리자 권한 여부 (소프트웨어 설치 가능?)
[ ] 3-3. 인터넷 접속 가능 여부 + 차단 사이트 목록
[ ] 3-4. USB 사용 가능 여부
[ ] 3-5. 프록시/방화벽 정책 (외부 API 호출 가능?)
[ ] 3-6. Chrome 확장 프로그램 설치 가능 여부
[ ] 3-7. Office 애드인 설치 가능 여부
[ ] 3-8. PowerShell 실행 정책 (Restricted? RemoteSigned?)
```

---

### Phase 2: 교육 2주 전

#### 4. 도메인 화이트리스트 🌐

```
[ ] 4-1. IT팀에 아래 URL 화이트리스트 등록 요청:

  [Google 트랙]
  - gemini.google.com
  - aistudio.google.com
  - labs.google.com / opal.google
  - script.google.com
  - docs.google.com / sheets.google.com
  - notebooklm.google.com

  [Microsoft 트랙]
  - github.com / copilot.github.com
  - api.github.com
  - *.sharepoint.com / onedrive.live.com

  [Claude 트랙]
  - claude.ai / api.anthropic.com

  [공통]
  - api.upstage.ai (Document AI)
  - huggingface.co (모델 다운로드)
  - lmstudio.ai
  - ollama.com

[ ] 4-2. 화이트리스트 등록 완료 확인
[ ] 4-3. 접속 테스트 (수강생 PC에서 실제 접속 확인)
```

#### 5. 계정 준비 👤

```
[ ] 5-1. 수강생 Google 계정 준비 (Google 트랙)
        - 기업 Workspace 계정 사용? 또는 교육용 계정 별도 생성?
[ ] 5-2. 수강생 GitHub 계정 준비 (MS 트랙)
        - Copilot Business 라이센스 할당 확인
[ ] 5-3. 수강생 Claude 계정 준비 (Claude 트랙)
        - Teams Plan 라이센스 확인
[ ] 5-4. Upstage Document AI API 키 준비 (공통)
        - 강사가 교육용 API 키 사전 발급
```

#### 6. 5회차 로컬 AI 준비 (설치형) 🖥️

```
[ ] 6-1. LM Studio / Ollama 설치 가능 여부 최종 확인
[ ] 6-2. 설치 가능 → IT팀에 사전 일괄 설치 요청 또는 USB 배포 준비
[ ] 6-3. 설치 불가 → 플랜B 결정:
        - 강사 PC 화면 공유 시연 + 수강생은 웹 AI에서 동일 실습
[ ] 6-4. AI 모델 파일 사전 다운로드 (Solar Mini, Gemma4 — 각 2~4GB)
[ ] 6-5. 모델 배포 방법 결정 (USB? 사내 파일서버? 사전 설치?)
```

---

### Phase 3: 교육 3일 전

#### 7. 교육 자료 준비 📋

```
[ ] 7-1. 더미 데이터셋 5종 완성:
        - 자금일보 (가상 회사 "테스트주식회사")
        - 채권연령표 (가상 거래처 + 임의 금액)
        - 생산일보 (가상 공장 + 익명 작업자)
        - Document AI용 PDF (개인정보 마스킹 완료)
        - 대시보드용 KPI 데이터 (가상 수치)
[ ] 7-2. 80% 완성 템플릿 배포 준비 (Excel/Sheets 파일)
[ ] 7-3. 용어 사전 카드 인쇄 (A4 1장, 20개 용어)
[ ] 7-4. 회차별 따라하기 가이드 준비 (스크린샷 포함)
[ ] 7-5. 수강생 출석부 양식 준비 (ISMS-P 증빙용)
[ ] 7-6. 만족도 설문 양식 준비
```

#### 8. 최종 환경 테스트 ✅

```
[ ] 8-1. 교육장 빔프로젝터/모니터 확인
[ ] 8-2. 교육장 와이파이 속도 테스트 (20명 동시 접속)
[ ] 8-3. 수강생 PC 1대에서 전체 실습 리허설
[ ] 8-4. DRM 파일에서 VBA 실행 테스트 (MS 트랙)
[ ] 8-5. 각 AI 서비스 접속 테스트 (화이트리스트 동작 확인)
```

### Phase 4: 교육 당일

#### 9. 교육 시작 전 (30분 전) 🏃

```
[ ] 9-1. 수강생 PC 부팅 + AI 서비스 접속 확인
[ ] 9-2. 더미 데이터 파일 배포 확인
[ ] 9-3. 80% 완성 템플릿 배포 확인
[ ] 9-4. 빔프로젝터 + 강사 화면 공유 테스트
```

### Phase 5: 교육 종료 후

#### 10. 마무리 📊

```
[ ] 10-1. 만족도 설문 수거
[ ] 10-2. 교육 결과 보고서 작성 (ISMS-P 증빙)
[ ] 10-3. 수강생 데이터 정리 확인 (6회차 가이드 실행 여부)
[ ] 10-4. 미이수자 파악 + 추가교육 계획 수립
[ ] 10-5. 교육 자료(출석부, 설문, 보고서) 보관 (ISMS-P 3년)
```

## 출력 형식

$ARGUMENTS에 기업명이 있으면 해당 기업 맞춤, 없으면 범용 체크리스트 생성.

Word 또는 마크다운으로 출력:
- 35개 항목 체크리스트 (체크박스 포함)
- 기업 교육담당자에게 이메일로 보낼 수 있는 형태
- 담당자명/일정/트랙 등 빈칸 포함
