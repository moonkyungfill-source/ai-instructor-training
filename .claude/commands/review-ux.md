# 비개발자 관점 수업 따라하기 검토

## 목적

수업계획서를 비개발자 직장인 관점에서 "실제로 따라할 수 있는지" 검토

## 검토 에이전트 구성 (3명 병렬)

### 1. 실제 수강생 역할
- 40대 사무직, 엑셀만 사용, 코딩/터미널 경험 없음
- 각 실습을 😊쉬움 / 😐보통 / 😰어려움 / 🚫불가능으로 평가
- "이거 뭔 소린지 모르겠는데요" 관점

### 2. 교육 설계 전문가 역할
- 인지 부하, scaffolding, 성공 경험 설계, 전문 용어 검토
- 회차당 새 도구/개념 수 체크 (한계: 2개)
- 30분 성공 경험 블록 확인

### 3. IT 인프라 관리자 역할
- 관리자 권한 없는 Windows PC에서 각 도구 사용 가능성
- [가능] / [조건부] / [불가] 판정
- 도메인 화이트리스트, 사전 IT 요청 사항

## 출력 형식

각 리뷰어의 결과를 종합하여:
1. CRITICAL (반드시 바꿔야 할 것)
2. 회차별 개선안
3. 필수 준비물 체크리스트
