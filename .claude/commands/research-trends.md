# 2026 AI 트렌드 리서치

## 목적

강의 기획서 및 지원서 작성을 위한 2026년 AI 트렌드 조사

## 조사 영역

### 핵심 트렌드
1. **AI Agent & Agentic Workflow**
   - MCP (Model Context Protocol)
   - Tool Use & Function Calling
   - Multi-Agent Orchestration
   - Agent-to-Agent Communication (A2A)

2. **LLM 애플리케이션 개발**
   - RAG (Retrieval Augmented Generation) 고도화
   - Fine-tuning 전략 (LoRA, QLoRA, RLHF)
   - Prompt Engineering 고급 기법
   - LLM Evaluation & Observability

3. **Document AI & Structured Extraction**
   - OCR + LLM 파이프라인
   - 문서 이해 및 데이터 추출
   - 업스테이지 Document AI 활용

4. **On-device & Edge AI**
   - 소형 모델 (SLM) 활용
   - 온디바이스 추론 최적화

5. **AI 거버넌스**
   - EU AI Act 시행
   - 기업 AI 윤리 가이드라인
   - 책임있는 AI 개발

### 업스테이지 기술 동향
- Solar LLM 최신 버전 및 성능
- Document AI 제품군
- 업스테이지 API 및 개발자 도구

## 작업 흐름

1. WebSearch로 각 영역별 최신 동향 조사
2. 업스테이지 공식 블로그/뉴스 확인
3. 주요 AI 컨퍼런스 (NeurIPS, ICML, AAAI 2026) 키워드 확인
4. 산업별 AI 도입 트렌드 파악
5. 조사 결과를 `research/` 디렉토리에 정리

## 출력 형식

```markdown
# 2026 AI 트렌드 리서치 결과

## 1. [트렌드명]
- **현황**: ...
- **핵심 기술**: ...
- **교육 커리큘럼 반영 포인트**: ...
- **출처**: ...

## 2. [트렌드명]
...
```

## 주의사항

- $ARGUMENTS 에 특정 영역이 지정되면 해당 영역만 심층 조사
- 강의 기획서에 반영 가능한 형태로 정리
- 출처 명시 필수
