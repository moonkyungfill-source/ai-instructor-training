## Google 트랙 추가 발견

| 항목 | 경고 |
|------|------|
| Gemini Activity | 끄기 설정해도 이미 저장된 데이터는 72시간 내 처리. **완전 비학습 보장 아님** |
| AI Studio 무료 | 입력/출력 **모두** 학습 + **인간 리뷰어가 읽을 수 있음** |
| Apps Script + Gemini API | 스크립트 자체는 안전, **스크립트가 호출하는 Gemini API**가 학습 대상 |
| Drive + Gemini 연동 | Drive 저장은 안전, **Gemini가 Drive 파일을 읽는 순간** 학습정책 적용 |
| OAuth scope | Drive API 연결 시 **broad scope = 전체 Drive 접근** → 최소 권한 필수 |
| 실습 전용 계정 | 개인/업무 계정의 Drive에 AI 연결하면 **모든 파일이 AI에 노출** |

## 3트랙 강사 매 회차 첫 슬라이드

```
1. 무료 AI에 입력하는 모든 내용은 AI 학습에 사용될 수 있습니다.
2. 오늘 실습은 제공된 더미 데이터로만 진행합니다. 실제 회사/고객 데이터 입력 금지.
3. 실습 종료 후 생성된 모든 파일과 대화 기록을 삭제하세요.
```

## 강사 필수 조치 5가지

### 1. 더미 데이터셋 사전 제작 (CRITICAL)

모든 실습에 사용할 가상 데이터:
- 가상 회사: "테스트주식회사", "AI교육(주)"
- 가상 인물: "홍길동", "김테스트"
- 가상 금액: 임의 숫자
- 가상 계좌: "000-000-000000"
- Document AI용 가상 세금계산서 PDF

### 2. 매 회차 3분 보안 브리핑

수업 시작 전 반드시 말할 것:
> "오늘 사용하는 [도구명]은 [무료/유료] 플랜에서 [학습 사용됨/안전합니다]. 
> 실제 업무 데이터, 개인정보, 회사 기밀은 절대 입력하지 마세요.
> 제공된 더미 데이터만 사용합니다."

### 3. OneDrive/Artifacts 공유 시 접근 통제

- OneDrive: "특정 사용자" 지정 필수, "모든 사람" 금지
- Artifacts: Publish 버튼 금지
- Opal: 링크 공유 시 범위 확인
- **만료일 설정** 필수

### 4. 교육 후 데이터 정리 체크리스트

```
□ AI 대화 기록 삭제 (Gemini/Copilot/Claude)
□ Artifacts/Projects 삭제
□ MCP 설정 파일 제거
□ OneDrive 실습 파일 삭제 + 휴지통 비우기 (93일 보관!)
□ Ollama/LM Studio 대화 히스토리 삭제
□ 작업 스케줄러 자동화 작업 비활성화
□ 더미 데이터 파일 정리
```

### 5. ISMS-P 교육 증빙 양식

```
□ 교육 계획서 (수업계획서)
□ 출석부
□ 교육 자료 (실습 템플릿, 더미 데이터)
□ 결과 보고서 (프로젝트 발표 결과)
□ 만족도 설문
□ 미이수자 추가교육 계획
□ 데이터 정리 확인서
```
