### B. 기업교육 설계 전문가 (Instructional Designer)

> "4회차 도구 5개는 학습이 아니라 데모 관람"

| 항목 | 판정 | 핵심 문제 |
|------|------|-----------|
| 인지 부하 | **심각** | 2~4회차에 새 도구 5~7개 → 회차당 2개가 한계 |
| Scaffolding | **구조 결함** | 1회차부터 Ollama CLI → 첫 수업에서 좌절 |
| 성공 경험 | **부족** | 30분 내 "됐다!" 순간이 없는 회차 있음 |
| 전문 용어 | **심각** | 18개 이상 새 용어 → 체험 먼저, 이름은 나중에 |
| 실습 비율 | **편차 심함** | 3회차 25%(개념 폭발) ↔ 5회차 75% |

**핵심 원칙 3가지:**
1. **"하나의 회차 = 하나의 큰 성공 경험"**
2. **30분 안에 결과물이 화면에 나와야 한다**
3. **체험 먼저, 이름은 나중에** (실습 → "방금 한 게 Agent입니다")

## CRITICAL: 반드시 바꿔야 할 5가지

### 1. 🚨 1회차에서 Ollama 설치 빼기
- 첫 수업 = "AI가 유용하다" 느끼게 하는 것
- 설치 실패 좌절이 아닌, 웹 AI로 즉각 성공 경험
- Ollama는 5회차로 이동

### 2. 🚨 4회차 도구 5개 → 1~2개로 축소
- Opal+Mixboard+Pomely+HTML+로컬공유 = 데모 관람
- **하나를 제대로 > 다섯을 어렴풋이**

### 3. 🚨 매 회차 "30분 성공 경험" 의무 배치
- 수업 시작 30분 안에 수강생 화면에 결과물
- 이것이 나머지 3시간 30분 집중력을 담보

### 4. 🚨 설치형 도구 → 웹 기반 대안 준비
- Ollama 불가 → Google AI Studio / Claude.ai 웹
- python http.server 불가 → Opal 링크 공유 / 파일 공유
- Copilot CLI 불가 → ChatGPT/Claude 웹에서 코드 생성

### 5. 🚨 "체험 먼저, 이름은 나중에" 원칙
- ❌ "오늘은 Agentic Workflow를 배우겠습니다" → 정의 → 실습
- ✅ "AI가 혼자 판단해서 일하게 해봅시다" → 실습 → "방금 한 게 Agent입니다"

## 개선된 커리큘럼 제안

| 회차 | 현재 (문제) | 개선안 | 성공 경험 (30분) |
|------|-----------|--------|-----------------|
| **1** | Ollama 설치 + 보안 (좌절) | **AI 첫 만남 + 보안** — 웹 AI로 즉시 체험, 설치 없음 | "AI가 보고서 초안을 3분에 써줬다" |
| **2** | 3개 주제 과부하 | **자금일보 자동화 하나만 깊이** + Document AI 맛보기 | "버튼 하나로 자금일보 완성" |

| **6** | 종합 (조합 어려움) | **단계별 가이드** 제공 + 페어 학습 | "내 업무가 자동화됐다!" |
