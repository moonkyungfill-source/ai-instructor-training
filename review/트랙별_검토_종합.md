# 3트랙 수업계획서 종합 검토 리포트

## 공통 이슈 (3트랙 모두 해당)

| # | 이슈 | 심각도 | 해결 방향 |
|---|------|--------|----------|
| 1 | **2회차 과부하** (프롬프트+스프레드시트+Document AI = 3개 주제) | 높음 | Document AI를 데모로 축소 또는 다른 회차로 이동 |
| 2 | **4회차 과부하** (바이브코딩+대시보드+로컬공유+추가도구) | 높음 | 도구 2개 이하로 축소, 나머지는 시연만 |
| 3 | **3→4→5 회차 전환이 끊김** | 중간 | 스토리라인 명시: 자동화→시각화→자립 |
| 4 | **Ollama 설치 리스크** (기업 PC 권한, 네트워크) | 높음 | 사전 USB 배포 + 강사 PC 시연 플랜B |
| 5 | **"월요일 액션 플랜" 없음** | 중간 | 매 회차 마지막 15분에 "다음 주 적용할 것 1개" |

| 항목 | 현재 | 개선 |

| 4회차 | Opal+Mixboard+Pomely+HTML+로컬공유 (5개) | **Opal 미니앱 + 로컬 공유** (2개). Mixboard/Pomely는 시연만 |

## Microsoft 트랙 개선안

| 항목 | 현재 | 개선 |
|------|------|------|
| Copilot CLI | 터미널 기반 → 비개발자 장벽 높음 | **Copilot in Excel/웹 UI** 우선, CLI는 선택 심화 |

| 매력도 | VBA 편집기 = 회색 화면 | 1회차에 **킬러 데모**(완성 대시보드) 먼저 시연 |

## 공통 스토리라인 (개선안)

```
1회차 [기초]  AI를 안전하게 쓰는 법 + 킬러 데모(완성품 먼저 보여주기)
   ↓
2회차 [활용]  프롬프트로 AI에게 시키기 + 업무 문서 자동화 (1개만 깊이)
   ↓
3회차 [심화]  AI Agent로 복잡한 업무를 자동화 (워크플로우 파이프라인)
   ↓
4회차 [시각화] 3회차 결과를 대시보드로 만들고 팀에 공유
   ↓
5회차 [자립]  로컬 AI로 인터넷 없이도 (Solar vs Gemma)
   ↓
6회차 [통합]  전부 연결 + 월요일 액션 플랜
```
